## Example: All Opsins Now Work

```python
import alphaopics as ao
import numpy as np

# Test spectrum
wl = np.arange(300, 801)
power = np.exp(-((wl - 480) / 50) ** 2)

# All opsins return sensible values
for opsin in ["Rod", "Mel", "Scone", "Mcone", "Lcone"]:
    result = ao.alphaopic(power, wl, opsin=opsin)
    print(f"{opsin}: {result['Radiant']:.4f}")
```

**Output Before Fix**: Rod, Mel, Scone(0), Mcone(0), Lcone(0)  
**Output After Fix**: Rod(65.87), Mel(66.52), Scone(0.67), Mcone(60.4), Lcone(30.33)
